# BerufeTracker

[English](../README.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Português](pt-BR.md) · [Italiano](it.md) · [Русский](ru.md) · [한국어](ko.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md)

要把专业练到 300，你还需要多少铜矿石、亚麻布和宁神花？BerufeTracker 帮你算出来：每个专业都会分解到基础材料，并涵盖你所有的角色和银行。

适用于 **WoW Forever**，使用你游戏客户端的语言：英语、德语、法语、西班牙语、葡萄牙语、意大利语、俄语、韩语和中文（简体和繁体）。

## 功能

**材料**
- 所有专业的总需求，分解到基础材料。例如，青铜锭会计为铜锭和锡锭，而它们又会计为矿石。
- 会扣除你当前阵营所有角色的背包、银行和邮箱中的物品。如果安装了 [BagBrother/Bagnon](https://www.curseforge.com/wow/addons/bagnon)，BerufeTracker 尚不认识的角色也会被计入。
- 筛选：“当前角色”（默认）只显示登录角色的专业。“所有角色（已学专业）”将你阵营的所有角色按各自的专业和技能等级相加。“已学专业（最佳角色）”将每个已学专业计算一次，“所有专业（包括未学）”将每个专业计算一次（未学的从 1 开始），也可以只选择单个角色。路线只显示所选的专业；选择单个角色时，尚未学习的专业只显示第一位训练师。采集专业可以排除。
- 鼠标悬停时显示每个专业的需求、价格和购买花费、库存在各角色间的分布，以及材料的获取途径：采集点及所在区域、怪物及其等级，以及你阵营最近的商人。
- 拍卖行扫描会显示全部购买（而不是自己采集）需要花多少钱。材料和路线显示相同的购买花费，包括训练师和配方。

**路线**
- 每个专业的分步路线，以及还剩多少未完成。
- 选择指南：Metabot、RankedBoost、Wowhead、wowtbc.gg、GoldGoblin 或 wow-professions，可按专业单独选择，也可全部统一设置。
- **最便宜的计算路线：** 独立于其他指南的自有指南。每个技能点都会从该专业全部配方（Forever 游戏数据）中，按配方颜色和升级几率选出最便宜的一个，计入拍卖行、商人、训练师和配方价格。已学会的配方和已有材料按免费计算；商人限量出售的物品只有在拍卖行有货时才计入；有冷却时间的配方不使用。**最便宜的指南路线** 用其他指南的步骤做同样的计算。**最快的计算路线** 选择制作时间最短的配方，并计入月布等材料的冷却时间。自有路线绝不会比其他任何指南更贵，并会在打开窗口时重新计算。
- 每个指南都会显示从当前技能开始的制作时间和花费；指南菜单会比较所有指南的花费。
- 缺少的配方会被标出，并注明获取地点。
- 拜访训练师会出现在路线中合适的位置，并附上能教你下一等级的最近训练师。

**路径点**
- 左键点击训练师或材料，可设置前往最近训练师或商人的路径点；再次点击会切换到列表中的下一个。点击路线步骤或可制作材料会打开专业窗口并选好配方和数量；缺少配方时会引导你前往配方商人或训练师。
- 一个带方向箭头和说明的条会显示目标。点击它会打开地图并定位到目标。
- 地图上也会显示标签。在聊天中分享地图标记时，说明会一并发送。
- 一旦你与该 NPC 对话，路径点就会消失。

**游戏内**
- 物品鼠标提示（背包、银行、拍卖行、拾取）会显示在当前筛选下你还需要多少。
- 世界中的矿脉和草药会显示你还需要从中获得多少，以及大约还应采集多少次：直到变灰以及为你的专业所需。
- **突出显示可采集物**（材料标签页或 `/berufe glitzern`）：附近的草药、矿脉和可剥皮的野兽会发光，需要该材料或采集仍能提升技能时为亮色，否则为灰色。角色学会草药学、采矿或剥皮时自动开启（游戏只提供约15米内最近的一个对象）。另有 **声音**（旁边或 `/berufe glitzern ton`）：附近出现可采集的目标时播放轻声提示。可与 PÄNIK Gildentools 一起运行；请在那里关闭矿石和草药，否则两者都会发光。
- **采集区域**（路线标签页，草药学、采矿、剥皮和钓鱼下方）：按密度和距离列出适合当前技能的最佳地图，并标出每张地图值得采集的技能范围，便于判断何时换地方。点击：打开显示刷新点和路线的地图（小地图上也显示）；右键可显示或隐藏刷新点和路线（选择会保留）。草药、矿石和野兽来自 QuestieDB 的 WoW Forever 数据；钓鱼按经典旧世各区域的最低技能。在世界地图上将鼠标移到区域上时，会在区域名称下方显示角色已学会的采集专业的技能范围。世界地图左下角的面板可开关专业（草药为方块，矿石为菱形，各有路线颜色）、单个材料和技能颜色。数据中缺少的草药和矿点会在采集时自动记录。
- 敌人会显示它们掉落哪些你需要的材料，以及同等级人型生物的布料和野兽的皮革（剥皮）。
- 武器和护甲会显示分解大约能得到哪些你需要的附魔材料。
- 游戏的专业窗口会为路线下一步推荐的配方加上边框；鼠标悬停时显示推荐它的指南、所需材料以及哪些角色持有它们。专业窗口侧边（专业图标和 ATT 标签旁）的 BerufeTracker 标签会把 BerufeTracker 窗口连同该专业的路线停靠在旁边；再次点击即取消停靠。

**窗口**
- 角色标签页：每个角色的等级、公会、金币、专业和材料；公会银行按其公会中角色的顺序排列。你可以选择计入哪些库存。
- 窗口大小可以调整；展开的专业会按角色记住。

## 用法

- `/berufe` 或小地图按钮可打开窗口。
- 要获取价格，请打开拍卖行并点击“扫描价格”（或输入 `/berufe scan`）。
- `/berufe skill <专业> <数值>` 可在技能未被识别时手动设置。不带数值时将重新使用自动识别。
- 每个角色都需要启用插件登录一次，才能识别其专业。银行只要打开一次就会被记录。

## 限制

- 物品、训练师、商人和采集点的名称来自游戏和 QuestieDB。意大利语以及少数没有制造物品的配方（例如附魔）的名称会以英文显示。配方获取地点仅有德语和英语版本，因此在中文下会以英文显示。
- 距离为直线距离，且仅在同一大陆上有效。
- 并非每个配方都有已知的获取地点。
- 商人和地点数据来自 QuestieDB，可能存在个别错误。
