# BerufeTracker

[English](../README.md) · [Deutsch](de.md) · [Français](fr.md) · [Español](es.md) · [Português](pt-BR.md) · [Italiano](it.md) · [Русский](ru.md) · [한국어](ko.md) · [简体中文](zh-CN.md) · [繁體中文](zh-TW.md)

要把專業練到 300，你還需要多少銅礦石、亞麻布和寧神花？BerufeTracker 幫你算出來：每個專業都會拆解到基礎材料，並涵蓋你所有的角色和銀行。

適用於 **WoW Forever**，使用你遊戲用戶端的語言：英文、德文、法文、西班牙文、葡萄牙文、義大利文、俄文、韓文和中文（簡體和繁體）。

## 功能

**材料**
- 所有專業的總需求，拆解到基礎材料。例如青銅錠會計為銅錠和錫錠，而它們又會再計為礦石。
- 會扣除你目前陣營所有角色的背包、銀行和信箱中的物品。若有安裝 [BagBrother/Bagnon](https://www.curseforge.com/wow/addons/bagnon)，BerufeTracker 還不認識的角色也會一併計入。
- 篩選：「目前角色」（預設）只顯示登入角色的專業。「所有角色（已學專業）」會把你陣營的所有角色依各自的專業和技能等級加總。「已學專業（最佳角色）」將每個已學的專業計算一次，「所有專業（包括未學）」將每個專業計算一次（未學的從 1 開始），也可以只選擇單一角色。路線只顯示所選的專業；選擇單一角色時，尚未學習的專業只顯示第一位訓練師。採集專業可以排除。
- 滑鼠指向時會顯示各專業的需求、價格與購買花費、庫存在各角色間的分布，以及材料的取得方式：採集點與所在區域、怪物與其等級，以及你陣營最近的商人。
- 拍賣場掃描會顯示全部用買的（而不是自己採集）要花多少錢。材料和路線顯示相同的購買花費，包括訓練師和配方。

**路線**
- 每個專業的逐步路線，以及還剩多少未完成。
- 選擇指南：Metabot、RankedBoost、Wowhead、wowtbc.gg、GoldGoblin 或 wow-professions，可依專業個別選擇，也可全部一起設定。
- **最便宜的計算路線：** 獨立於其他指南的自有指南。每個技能點都會從該專業全部配方（Forever 遊戲資料）中，依配方顏色和升級機率選出最便宜的一個，計入拍賣場、商人、訓練師和配方價格。已學會的配方和已有材料以免費計算；商人限量販售的物品只有在拍賣場有貨時才計入；有冷卻時間的配方不使用。**最便宜的指南路線** 用其他指南的步驟做同樣的計算。**最快的計算路線** 選擇製作時間最短的配方，並計入月布等材料的冷卻時間。自有路線絕不會比其他任何指南更貴，並會在開啟視窗時重新計算。
- 每個指南都會顯示從目前技能開始的製作時間和花費；指南選單會比較所有指南的花費。
- 缺少的配方會被標示出來，並註明取得地點。
- 拜訪訓練師會出現在路線中適當的位置，並附上能教你下一個等級的最近訓練師。

**導航點**
- 左鍵點擊訓練師或材料，可設定前往最近訓練師或商人的導航點；再次點擊會切換到清單中的下一個。點擊路線步驟或可製作材料會開啟專業視窗並選好配方和數量；缺少配方時會引導你前往配方商人或訓練師。
- 一條帶有方向箭頭和說明的列會顯示目標。點擊它會開啟地圖並定位到目標。
- 地圖上也會顯示標籤。在聊天中分享地圖標記時，說明會一起送出。
- 只要你和該 NPC 對話，導航點就會消失。

**遊戲中**
- 物品滑鼠提示（背包、銀行、拍賣場、拾取）會顯示在目前篩選下你還需要多少。
- 世界中的礦脈和草藥會顯示你還需要從中取得多少，以及大約還應採集幾次：直到變灰以及為你的專業所需。
- **標示可採集物**（材料分頁或 `/berufe glitzern`）：附近的草藥、礦脈和可剝皮的野獸會發光，需要該材料或採集仍能提升技能時為亮色，否則為灰色。角色學會草藥學、採礦或剝皮時自動開啟（遊戲只提供約15公尺內最近的一個物件）。另有 **聲音**（旁邊或 `/berufe glitzern ton`）：附近出現可採集的目標時播放輕聲提示。可與 PÄNIK Gildentools 一起運作；請在那裡關閉礦石和草藥，否則兩者都會發光。
- **採集區域**（路線分頁，草藥學、採礦、剝皮和釣魚下方）：依密度和距離列出適合目前技能的最佳地圖，並標出每張地圖值得採集的技能範圍，方便判斷何時換地方。點擊：開啟顯示重生點和路線的地圖（小地圖上也顯示）；右鍵可顯示或隱藏重生點和路線（選擇會保留）。草藥、礦石和野獸來自 QuestieDB 的 WoW Forever 資料；釣魚依經典舊世各區域的最低技能。在世界地圖上將滑鼠移到區域上時，會在區域名稱下方顯示角色已學會的採集專業的技能範圍。世界地圖左下角的面板可開關專業（草藥為方塊，礦石為菱形，各有路線顏色）、單個材料和技能顏色。資料中缺少的草藥和礦點會在採集時自動記錄。
- 敵人會顯示它們掉落哪些你需要的材料，以及同等級人型生物的布料和野獸的皮革（剝皮）。
- 武器和護甲會顯示分解大約能得到哪些你需要的附魔材料。
- 遊戲的專業視窗會為路線下一步建議的配方加上邊框；滑鼠懸停時顯示建議它的指南、所需材料以及哪些角色持有它們。專業視窗側邊（專業圖示和 ATT 分頁旁）的 BerufeTracker 分頁會把 BerufeTracker 視窗連同該專業的路線停靠在旁邊；再次點擊即取消停靠。

**視窗**
- 角色分頁：每個角色的等級、公會、金幣、專業和材料；公會銀行依其公會中角色的順序排列。你可以選擇計入哪些庫存。
- 視窗大小可以調整；展開的專業會依角色記住。

## 使用方式

- `/berufe` 或小地圖按鈕可開啟視窗。
- 若要取得價格，請開啟拍賣場並點擊「掃描價格」（或輸入 `/berufe scan`）。
- `/berufe skill <專業> <數值>` 可在技能無法偵測時手動設定。不加數值則會重新套用自動偵測。
- 每個角色都需要啟用插件登入一次，才能得知它的專業。銀行只要開啟一次就會被記錄。

## 限制

- 物品、訓練師、商人和採集點的名稱來自遊戲和 QuestieDB。義大利文以及少數沒有製造物品的配方（例如附魔）的名稱會以英文顯示。配方取得地點只有德文和英文版本，因此在中文下會以英文顯示。
- 距離為直線距離，且只在同一塊大陸上有效。
- 並非每個配方都有已知的取得地點。
- 商人和地點資料來自 QuestieDB，可能有個別錯誤。
