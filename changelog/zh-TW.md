# Changelog

## 1.5.0

- 採集區域：在草藥學、採礦、剝皮和釣魚下方，路線依密度和距離列出適合目前技能的最佳地圖，並標出值得採集的技能範圍和難度顏色。點擊開啟地圖，右鍵全部隱藏
- 世界地圖：在每張區域地圖和小地圖上顯示採集專業的重生點和路線；草藥為方塊，礦石為菱形
- 地圖面板（左下角按鈕）：開關草藥學和採礦、兩者的合併路線、帶圖示的單個材料以及技能顏色（灰色到紅色）
- 在世界地圖上將滑鼠移到區域上時，會顯示你採集專業在該區域的技能範圍
- 資料中缺少的採集點會在採集時自動記錄
- 釣魚：每個區域的技能範圍，並推薦仍能穩定釣到東西的最高區域
- 訓練師：補充了大量缺失的訓練師（其他頭銜、WoW Forever 訓練師）；依遊戲中觀察，訓練師比經典舊世多教一個等級
- 點擊訓練師或材料：在最近的目標設定路徑點並開啟地圖，再次點擊切換到下一個（「訓練師 1/18」）
- 專業視窗上的 BerufeTracker 分頁（ATT 分頁旁）：將目前專業的路線停靠在旁邊
- 發光和聲音只針對已學會的採集專業；能辨識仍有戰利品的可剝皮屍體；可與 PÄNIK 的 NPC 暫停配合使用
- 敵人提示：以該野獸對應的技能顏色顯示「剝皮」；不可剝皮的野獸不再顯示皮革
- 草藥和礦石提示顯示目前獲得技能點的機率
- 路徑點列現在位於小地圖旁
- 點擊路線步驟或可製作材料：開啟專業視窗並選中配方、填好數量（最多為目前可製作數量）；缺少配方時：設定前往配方商人或訓練師的路徑點
- 路線步驟和可製作材料的提示顯示製作時目前獲得技能點的機率
- 右鍵點擊小地圖按鈕、地圖按鈕或採集區域：顯示或隱藏重生點和路線；選擇會保留

## 1.4.0

- 「標示可採集物」（原「標示礦石/草藥」）在角色學會草藥學、採礦或剝皮時自動開啟，閃光效果大幅增強：脈動光暈、光柱以及環繞物件閃爍的星星
- 剝皮：可剝皮的野獸也會發光（淺米色），技能不足時為灰色
- 旁邊新增選項「聲音」（或 /berufe glitzern ton）：附近出現可採集目標時輕聲提示，每個物件一次；與發光無關
- 與 PÄNIK Gildentools 一起運作，而不再保持關閉；請在那裡關閉礦石和草藥，否則兩者都會發光
- 草藥和礦石的提示末尾增加一個空行，與其他插件的行分開

## 1.3.2

- 小地圖按鈕：提示中顯示簡短說明以及點擊和拖曳的作用
- 若其他插件提供 LibDBIcon，小地圖按鈕會使用它，按鈕收納插件（如 Leatrix Plus）會以自身提示顯示該按鈕
- 插件列表顯示版本號，而不是「@project-version@」

## 1.3.1

- 新選項「標示礦石/草藥」（材料分頁或 /berufe glitzern）：附近的草藥和礦脈會發光，需要該材料或採集仍能提升技能時為亮色；若 PÄNIK Gildentools 或其他插件已在做，則保持關閉
- 計算路線會先使用已有材料，只要它們還能提升技能（例如先做抗毒藥再做毛料繃帶，先做泥鯛魚再做鯰魚）；最快路線僅在不增加時間時如此
- 只有當路線角色擁有該專業時，配方才依該角色是否學會計算；否則計入你其他角色的配方
- 草藥和礦石的滑鼠提示：大約還需採集幾次，直到變灰以及為你的專業所需
- 滑鼠提示：「仍缺」顯示為紅色

## 1.3.0

- 新的自有指南「最快的計算路線」：選擇製作時間最短的配方，並計入月布等材料的冷卻時間
- 每個專業下顯示每個指南從現在起的製作時間和花費
- 「最便宜的指南路線」現在像「最便宜的計算路線」一樣逐個技能點計算；兩者都絕不會比其他任何指南更貴
- 自有路線依每個技能點計算升級機率，已有材料只在夠用時使用
- 製作後不再卡頓：自有路線在開啟視窗時於背景計算
- 新的預設篩選「目前角色」；篩選更名為「所有角色（已學專業）」「已學專業（最佳角色）」和「所有專業（包括未學）」。路線只顯示所選的專業，未學的只顯示第一位訓練師
- 材料和路線顯示相同的購買花費，包括訓練師、配方以及無價格材料的估算
- 遊戲的專業視窗：路線下一步建議的配方帶有細邊框和淺色背景；滑鼠懸停時顯示建議它的指南、材料以及哪些角色持有它們
- 草藥和礦石：滑鼠提示顯示採集是否還能提升技能
- 角色分頁：每個角色的等級、公會、金幣、專業和材料；公會銀行排在其公會角色之後
- 金幣數額顯示硬幣圖示
- 視窗：最小尺寸，更清楚的縮排；展開的專業依角色記住
- 修正：角色的背包、技能和配方可能在登出時遺失

## 1.2.0

- 兩個自有指南：「最便宜的計算路線」（根據 Forever 遊戲資料中該專業的全部配方：每個技能點依顏色和機率選出最便宜的配方）和「最便宜的指南路線」（根據其他指南的步驟）
- 指南選單和「全部使用指南：」旁顯示每個指南從現在起的費用，包括訓練師和配方費用；已有材料以免費計算
- 商人限量販售的物品只有在拍賣場有貨時才計入；價格掃描現在也包括配方
- 中間產品（布卷、錠 …）在拍賣場比自己製作便宜時直接購買
- 路線跟隨篩選中選擇的角色；先顯示主專業，然後是急救和烹飪，釣魚排在最後
- 標記冷卻時間長或只能透過任務取得的步驟
- 視窗大小可調整
- 敵人提示顯示其掉落的所需材料，附帶機率和數量（資料：cMaNGOS）
- 分解：物品提示顯示可能的結果，附帶機率和數量
- 任何路線都不需要的商業技能材料顯示「任何路線都不需要」
