# Changelog

## 1.2.0

- 자체 가이드 두 가지: "가장 저렴한 계산 경로"(Forever 게임 데이터의 전문기술 모든 제조법에서 숙련도 1점마다 색상과 확률에 따라 가장 저렴한 제조법)와 "가장 저렴한 가이드 경로"(다른 가이드의 단계에서)
- 가이드 메뉴와 "전체 가이드:" 옆에 모든 가이드의 지금부터 비용 표시, 훈련사·제조법 비용 포함; 이미 가진 재료는 무료
- 재고가 한정된 상인 물품은 경매장에 있을 때만 계산; 가격 검색에 제조법 아이템도 포함
- 중간 재료(옷감, 주괴 …)는 직접 만드는 것보다 저렴하면 경매장에서 구입
- 경로가 필터에서 선택한 캐릭터를 따름; 주 전문기술 먼저, 그다음 응급치료와 요리, 낚시는 마지막
- 재사용 대기시간이 긴 단계나 퀘스트로만 얻는 단계를 표시
- 창 크기 조절 가능
- 적 툴팁에 필요한 재료 중 무엇을 떨어뜨리는지 확률과 수량과 함께 표시 (데이터: cMaNGOS)
- 마력 추출: 아이템 툴팁에 가능한 결과를 확률과 수량과 함께 표시
- 어떤 경로에도 필요 없는 직업 재료에 "어떤 경로에도 필요 없음" 표시

- 모든 게임 언어로 된 README

## 1.1.0

- 모든 게임 언어 지원: 영어, 독일어, 프랑스어, 스페인어, 포르투갈어, 이탈리아어, 러시아어, 한국어, 중국어(간체 및 번체)
- 아이템, 제조법, 기술 전문가, 상인, 채집 지점의 이름을 게임 언어로 표시
- 전문 기술, 아이템, 제조법을 게임 언어와 관계없이 인식

## 1.0.1

- 경로에 기술 전문가 등급 "수습"(1-75) 추가
- 모든 등급에 범위 표시, 예: "숙련(75-150)"
- 완료한 등급에도 계속 기술 전문가 표시
- 현재 등급은 색상으로 강조되며 "남은 것만"에서도 계속 표시

## 1.0.0 – 첫 출시

- 모든 전문 기술 1–300의 재료 필요량을 기본 재료까지 분해하여 모든 캐릭터와 은행에 걸쳐 표시
- "모든 전문 기술" 필터는 각 캐릭터를 자신의 전문 기술 및 숙련도와 함께 합산; 그 외 "배운 전문 기술", "전문 기술마다 한 번"(배우지 않은 기술 포함), 개별 캐릭터; 채집 기술 제외 가능
- 필요량과 보유량은 현재 진영의 캐릭터만 계산
- 6개 가이드 중에서 경로 선택 가능, 제조법 상태 및 기술 전문가 방문 포함
- 비용 표시가 포함된 경매장 검색
- 재료별 획득처: 채집 지점, 몬스터, 가장 가까운 상인
- 기술 전문가와 상인까지의 경유지: 방향 화살표, 지도 표시, 대화창 링크 설명 포함
- 아이템 툴팁과 월드의 광맥 및 약초에 필요량 표시
- 전문 기술, 분류, 재료를 가나다순으로 정렬
